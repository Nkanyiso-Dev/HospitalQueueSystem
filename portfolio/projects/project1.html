7-Day Weather Forecast Application

An interactive web application designed to provide users with accurate weather forecasts for European cities. The project demonstrates skills in API integration, asynchronous JavaScript, and creating visually appealing interfaces.

Technology

HTML, CSS, JavaScript, 7Timer API

Features

  • Dynamic city selection from a CSV file
  • Real-time weather data fetching using 7Timer API
  • Visual representation of weather conditions using icons
  • 7-day forecast with daily highs and lows

Duration

1 month

Team Size

1 member

Challenges Faced

  • Handling CORS issues with local CSV files
  • Parsing and dynamically displaying weather data
