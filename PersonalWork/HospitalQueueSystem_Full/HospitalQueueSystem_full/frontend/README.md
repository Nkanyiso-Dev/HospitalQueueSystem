# Hospital Queue Management System — Frontend

A fully functional single-page dashboard built with vanilla HTML, CSS, and JavaScript.

## How to run

Just open `index.html` in any modern browser — no build tools, no dependencies, no server needed.

## Features

- Live priority queue dashboard — sorted by urgency automatically
- Register patients with urgency level selector
- Assign next patient to an available doctor with one click
- Discharge patients with clinical notes
- Doctors panel with availability status
- Discharge log with wait times and notes
- Live clock and real-time queue updates
- Toast notifications for all actions
- Fully responsive layout

## Tech stack

- Vanilla HTML5 / CSS3 / JavaScript (ES6+)
- Google Fonts: Inter + JetBrains Mono
- No frameworks, no dependencies
- Mirrors the Java backend OOP model exactly (Patient, Doctor, PatientRecord, UrgencyLevel)
